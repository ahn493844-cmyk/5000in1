# 5천만분의 1

대한민국에서 한 아기로 태어나 직접 살아 보는 인생 시뮬레이터입니다.

## 태어나기

출생신고서가 한 줄씩 채워지면서 "나와 같은 조건으로 태어난 사람"의 수가 줄어듭니다.

- 출생 연도(올해 또는 1950년 이후 아무 해), 성별, 출생지, 출생 순위
- 아버지·어머니의 나이와 직업(시대별 직업 분포), 가구 소득과 소득분위
- 가정 형편(빚에 쪼들림 ~ 재벌가), 집(자가·전세·월세), 부모님 사이, 성씨, 혈액형

## 살아가기

"1년 살기"를 누를 때마다 한 살씩 먹습니다. 건강·행복·지능·관계와 돈이 바뀌고, 중요한 순간에는 직접 고릅니다.

- 돌잡이, 방과 후, 중학교 생활, 고등학교(일반고·특성화고·자사고), 문과·이과
- 예비고사·학력고사·수능 성적에 따른 진학(의대·교대 포함), 재수, 입대
- 취업(대기업·공기업·공무원 시험·중소기업·생산직 등), 승진, 이직, 구조조정, 희망퇴직, 창업, 은퇴
- 연애와 결혼, 출산, 내 집 마련, 부모님 별세와 상속, 손주
- 질병(암·고혈압·당뇨), 사고, 그리고 죽음. 마지막에는 인생 성적표가 나옵니다.

집안 형편은 학원, 진학, 학자금 대출, 결혼 자금, 집 살 때 보태 주는 돈, 상속에 영향을 줍니다.
지난 시대에 태어나면 IMF 때 아버지가 실직하거나, 형편 때문에 중학교에 못 가는 일도 생깁니다.

## 파일

- `index.html`: 화면과 스타일
- `js/engine.js`: 통계와 규칙(브라우저 없이 Node로도 돌아갑니다)
- `js/ui.js`: 화면 그리기와 버튼

서버 없이 `index.html`을 브라우저로 열면 됩니다. GitHub Pages(main 브랜치, 루트)로도 바로 공개됩니다.

## 데이터

통계청(KOSIS) 인구동향·인구총조사·가계금융복지조사·경제활동인구조사·생명표, 국가암등록통계 등을 바탕으로 반올림한 근사치입니다.
수천 번 자동으로 살아 보면 평균 수명이 남자 약 81세, 여자 약 86세로 생명표 기대수명과 비슷하게 맞춰져 있습니다.
돈은 모두 지금 돈 가치로 계산합니다. 이름과 주민등록번호는 무작위로 만든 가짜입니다.
