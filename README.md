# 5천만분의 1

대한민국 사람 5,121만 명 가운데 한 명으로 무작위로 태어나는 인생 추첨 게임입니다.

나이, 성별, 사는 곳, 성씨, 혈액형, 학력, 경제활동, 업종, 소득, 혼인, 주거, 종교가 실제 통계 비율대로 정해지고,
조건이 하나 붙을 때마다 "나와 같은 조건의 사람" 숫자가 줄어듭니다.

그다음 **인생 연표**가 펼쳐집니다. 지금의 조건(학력·직업·혼인·주거)과 맞도록 태어나서 지금까지를 채우고,
지금 이후는 통계로 사망까지 시뮬레이션합니다.

- 출생 순서(세대별 형제 수), 돌잔치, 입학·졸업, 예비고사·학력고사·수능, 재수
- 병역(입대 연도별 복무 기간), 첫 취업, 이직, 창업, 퇴직·재취업·은퇴
- 결혼(세대·성별 평균 초혼 연령), 세대별 자녀 수, 육아휴직, 손주, 이혼·재혼·사별
- 내 집 마련, 독립, 이사, 부모님 별세
- 암 진단(평생 발생률·생존율), 사망 나이(곰페르츠 모형, 생명표 기대수명에 맞춤)와 사인
- 살아온 시절의 세상 사건(서울 올림픽, IMF, 한일 월드컵, 코로나19 등)

## 실행

`index.html` 하나로 동작합니다. 브라우저로 열면 바로 실행됩니다. 서버나 설치가 필요 없습니다.

## GitHub Pages로 공개하기

1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: **main**, 폴더 **/(root)** → Save
3. 잠시 뒤 `https://ahn493844-cmyk.github.io/5000in1/` 에서 열립니다.
