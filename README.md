# 5천만분의 1

대통령은 5천만 명 가운데 한 명입니다. 대한민국 어딘가에서 한 아기로 태어나, 저절로 흐르는 시간 속에서 정치인으로 살아 보는 시뮬레이터입니다.

## 태어나기

출생신고서가 한 줄씩 채워지면서 "나와 같은 조건으로 태어난 사람"의 수가 줄어듭니다.
출생 월, 성별, 출생지(시·도), 집안 형편, 부모님 정치 성향, 타고난 기질, 이름이 통계 비율대로 정해지고 고를 수 없습니다.

## 살아가기

시간은 한 달씩 저절로 흐릅니다. 멈춤·1배·3배·10배로 속도를 바꿀 수 있고, 선택이 필요하면 시간이 멈춥니다.

- 반장 선거, 수능, 대학과 전공, 대학 생활, 군 복무, 첫 직업(로스쿨·행정고시·언론사·보좌진·시민단체·노조·창업)
- 입당(푸른당·붉은당·새길당·무소속) 뒤 지방선거·총선·대선에 출마. 당선 가능성은 같은 판을 여러 번 굴려 미리 보여 줍니다.
- 당내 경선 → 본선 개표 방송. 기초의원 → 광역의원 → 기초단체장 → 국회의원 → 광역단체장 → 대통령
- 전당대회(당 대표), 장관·국무총리 제의, 돈 봉투, 검찰 수사와 수감, 대통령 국정 방향, 탄핵, 정계 은퇴, 그리고 죽음

## 정치판 (io)

같은 판에 컴퓨터가 움직이는 정치인 300여 명이 함께 살아갑니다. 이들도 나이를 먹고, 선거에 나가고, 장관이 되고, 기소되고, 은퇴합니다.

- 실시간 정치인 순위: 권력 점수(자리·인지도·당선 횟수)로 매기며 내 순위가 함께 나옵니다.
- 국회 300석: 총선마다 지역구 254석(시·도별 정치 성향 + 정권 심판 바람)과 비례 46석이 새로 채워집니다.
- 대통령 지지율이 달마다 움직이고, 지지율이 낮으면 여당이 선거에서 집니다.
- 경선과 본선의 상대는 순위표에 있는 바로 그 정치인들입니다.

## 파일

- `index.html`: 화면과 스타일
- `js/engine.js`: 통계와 규칙(브라우저 없이 Node로도 돌아갑니다)
- `js/ui.js`: 화면 그리기, 시간 흐름, 개표 애니메이션

서버 없이 `index.html`을 브라우저로 열면 됩니다. GitHub Pages(main 브랜치, 루트)로도 바로 공개됩니다.

## 데이터

출생 수·출생지·성씨 비율·기대수명은 통계청(KOSIS), 시·도별 정치 성향은 최근 총선·대선 양당 득표율, 의석 수와 지방선거 자리는 공직선거법을 바탕으로 반올림한 근사치입니다.
정당은 가상이며 다른 정치인의 이름은 무작위로 만들어 실제 인물과 관계없습니다.
수백 번 자동으로 살아 보면, 아무렇게나 고르면 대통령이 될 확률은 약 0.3%, 당선 가능성을 보고 영리하게 고르면 약 13%입니다.
